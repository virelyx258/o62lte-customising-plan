## 两点必须注意

**1. 槽位字节必须完全相等。** ROMFS 是绝对偏移顺序排布，替换文件的字节长度必须和原文件一模一样，否则后面所有文件的偏移整体平移、镜像损坏。正因为你的 PNG 是 144×144、与原厂一致，编码后长度天然相等，可以直接原地覆盖。

**2. 标注「需 I8 编码」的那几个，会被自动量化成 256 色。** 它们的槽位只有 21772 字节，装不下 ARGB8888（82956 字节），所以只能用索引色。实测对扁平图标平均误差 0.22/255，肉眼无差别；但如果你的图标有渐变/照片级内容，这几个会有可见色带。

`voice_alexa` 是 6005 字节的特例（`flags=0x0008`），格式未确定，建议先不动。

## 生成命令

```
python tools/iconpack.py make inputs/target/vela_app.bin <你的PNG目录> .work/mypack --patched
```

产出：`icons.patch`（补丁表）、`icons.rollback`（回滚包）、`payload/`（每个图标的 .bin）、`manifest.json`（含偏移与 SHA256）、`vela_app_patched.bin`（可直接写入的整分区镜像）。
